## Workflow

SOPs & process docs (Claude) → quality/throughput analysis (code execution) → maintenance knowledge (RAG over manuals) → supply research → comms.

## Core stack

Claude (docs + analysis) · a data/analytics tool · a RAG knowledge base over technical docs.

## Verdict

the win is knowledge capture and data analysis, not the shop floor (yet) — start with documentation and quality data.

## Gotchas

safety-critical decisions stay human; never trust AI on engineering specs unverified.
