## Workflow

map processes & draft SOPs (Claude) → analyse data (code execution) → automate repetitive multi-step work (Claude Cowork / a work agent) → coordinate (assistant tools) → monitor (dashboards).

## Core stack

Claude Cowork · Claude / code · a work agent.

## Verdict

ops is where agents earn their keep — repetitive multi-step work. Start with one process, end to end.

## Gotchas

don't automate a broken process; keep a human checkpoint on anything customer-facing.
