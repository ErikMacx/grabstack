## Workflow

build (Claude Code, Cursor) → review & refactor → research (Perplexity/Claude) → prototype (Claude) → build agents (frameworks) → document.

## Core stack

Claude Code (strongest agent on independent benchmarks) · Cursor (IDE) · Claude/GPT for design.

## Verdict

coding agents are the most mature, highest-ROI AI use today — this is the stack with the clearest payback.

## Gotchas

review all generated code; secure secrets and credentials; don't ship anything an agent wrote unread.
