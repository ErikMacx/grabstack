Meta released Muse Wonder and Muse Wonder Full on 12 October. Muse Wonder is available on the Meta Model API as muse-wonder-1.0, at $4 per 1M input tokens and $20 per 1M output tokens. Muse Wonder Full is available only to Muse Code subscribers. Meta claims state-of-the-art results on agent, memory and coding tests, but these are its own claims. VentureBeat reports that Artificial Analysis scored Wonder Full 56 on its Intelligence Index, against 58 for Claude Opus 5.5.
