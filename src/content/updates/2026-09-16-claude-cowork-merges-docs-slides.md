From 16 September, Claude Cowork and chat began merging into a single Claude, rolling out to Pro and Max plans over several weeks, so longer tasks can carry on after the user closes their laptop. Claude Docs and Claude Slides launched the same day in beta on paid plans, Claude Design now works inside conversations, and slides can be downloaded as PowerPoint or PDF. Anthropic said users found it frustrating to decide where a task belonged, so Claude now works out what a task needs using the skills and connectors the user already has.
