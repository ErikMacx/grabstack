Anthropic released Claude Opus 5.5 on 22 September as the first model in its Claude 5.5 family, saying it performs at the level of Claude Fable 5.1 on most work and costs 40% less to run than Opus 5. API pricing is $4 per million input tokens and $20 per million output tokens, and it is available on Anthropic's platform, AWS, Google Cloud and Microsoft Azure. Anthropic called it its first release since it argued for pacing the frontier, and said external evaluators including METR tested it before launch.
