---
term: "RAG (Retrieval-Augmented Generation)"
definition: "A technique that feeds a model relevant documents at query time so it can ground its answer in real data rather than relying solely on training knowledge."
tools: []
updated: "2026-06-03"
---

RAG retrieves context from an external source — a vector database, a search index, a file system — and injects it into the prompt. The model then generates an answer grounded in that retrieved material, reducing hallucination and keeping responses current.
