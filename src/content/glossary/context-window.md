---
term: "Context window"
definition: "The maximum amount of text (measured in tokens) a model can see in a single conversation — its working memory."
tools: []
updated: "2026-06-03"
---

Everything the model reads and writes in one session must fit inside the context window. Longer windows let models handle bigger documents and longer conversations, but cost more compute. Typical frontier windows range from 128K to 1M+ tokens.
