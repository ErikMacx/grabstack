Deep Research Max is the most thorough tier of Google's Deep Research agent, offered to developers through the Gemini API's Interactions API, where it must run in the background and be polled or streamed. It supports remote MCP servers, File Search, Google Search, code execution and charts, and is still a preview under the deep-research-max-preview-04-2026 ID. Google's docs now say only that it is powered by Gemini, so the earlier Gemini 3.1 Pro detail is removed as unconfirmed. No other material change found since 6 October 2026.
