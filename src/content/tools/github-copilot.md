GitHub Copilot covers code completion in editors, a cloud coding agent, the Copilot CLI and the Copilot desktop app, which is now available on every plan for macOS, Windows and Linux. Billing is fully usage-based: each plan carries a monthly allowance of AI credits (Pro 1,500 for $10, Pro+ 7,000 for $39, the new Max 20,000 for $100), organisations pay $0.01 per credit beyond their pool, and completions stay unlimited on paid plans. The model list now includes Claude Opus 5.5, GPT-6.1 Sol, Grok 4.7 and Microsoft's MAI-Code-1.1-Flash, while Free and Student users get models only through automatic selection. Since 1 October, computer use in public preview lets Copilot drive desktop applications that have no API, from the CLI or the app on macOS and Windows.
