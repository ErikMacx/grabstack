DeepSeek Harness is an open-source runtime that turns a model into an agent: it reads files, runs commands, keeps a plan and treats almost every capability as a swappable plugin. DeepSeek open-sourced it under the MIT licence in August 2026, and it works with DeepSeek-V4 or with other providers through OpenAI-compatible endpoints. The v0.2 developer preview in early October added official desktop apps for Apple-silicon Macs and 64-bit Windows that bundle the command-line tool, a plugin manager, a "creation mode" that builds new plugins from a chat description, document work across Word, Excel and PDF files, and scheduled recurring tasks. Its GitHub releases page shows steady v0.2.1 release candidates through October (adding DeepSeek-V4.1-Flash-1017 and DeepSeek Search and Fetch API support) and v0.2.2 pre-releases in early November, with mobile layout fixes and experimental worktree tools. It matters because a leading open-weight lab now ships its own free coding-and-work agent that is not locked to its models, though it is still a preview.
