OpenCode is an open-source coding agent from Anomaly that runs in the terminal, as a desktop app and inside IDEs, and connects to models from any provider, including Claude, GPT, Gemini and local models, or to free models it includes. Its paid options, OpenCode Zen (a curated set of models tested for coding agents) and OpenCode Go, sell model access rather than the tool itself. Its site now reports about 16 million monthly developers, more than any other open-source coding agent GrabStack tracks. For builders it is the main way to get a Claude Code-style agent without being tied to one model vendor.
