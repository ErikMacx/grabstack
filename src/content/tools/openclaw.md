OpenClaw is the MIT-licensed, self-hosted assistant Peter Steinberger released in November 2025; since he joined OpenAI it has been stewarded by an independent non-profit foundation with no paid tier. The August "2.0" release (v2026.8.1) was its biggest yet: setup that detects your existing model subscriptions and keys, a rebuilt browser app, shared cloud sessions with per-person access levels, consolidated memory, and approvals tied to the exact request and session, with sessions moved to SQLite. Critics, including The Register, noted the sandbox is still not on by default, so the security burden stays with whoever runs it. It remains the reference design the rest of the personal-agent field is measured against, and the obvious starting point if you want to own the machine, the models and the data.
