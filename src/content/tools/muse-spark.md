Meta has updated Muse Spark three times since June: 1.1 on 9 July, alongside a public preview of the Meta Model API; 1.2 in August with Muse Code, Meta's first coding agent; and 1.3 on 4 September. Meta says 1.3 is competitive with Claude Fable 5.1, while Artificial Analysis scored it 61 on its Intelligence Index against 66 for Fable 5.1, according to TechRepublic. At Meta Connect in September the Model API became generally available worldwide and Meta released Muse Glimmer, a separate 30B open-weights model. Muse Spark itself is not open-weight, but it is now a real, self-serve API option rather than a model locked inside Meta's apps.
