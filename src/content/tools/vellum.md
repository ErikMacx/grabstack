Vellum is a personal assistant with long-term memory that acts across your files and tools; its Credential Execution Service holds API keys, OAuth tokens and passwords, so the assistant knows which credential to use by alias but never sees the values. Self-hosted, everything except model calls and outbound messages stays on your Mac; the cloud option gives each user an isolated container on plans of $30, $100 or $200 a month. Since June it has shipped almost weekly: an Electron Mac app, real-time voice mode, an Android app (21 August), iOS control of a paired Mac, Windows installers and a Linux client, plus newer models such as GPT-6 Astra and Claude Fable 5.1. Its credential design is the clearest answer yet to the risk that an agent leaks the secrets it is handed.
