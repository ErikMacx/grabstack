Sora 2 is gone. OpenAI's deprecations page lists the Videos API and every Sora 2 model snapshot with a shutdown date of 24 September 2026 and no recommended replacement, and that date has now passed; the consumer web and app versions closed on 26 April 2026. OpenAI has left video generation entirely, so anyone who built on the Sora API needs another provider, such as Gemini Omni, Seedance, Kling or Veo. This entry stays only as a record.
