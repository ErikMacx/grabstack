Codex is OpenAI's coding agent, available as a CLI, IDE extensions and a cloud service and, since 9 July 2026, as one part of the new ChatGPT desktop app alongside Chat and Work. Since June it has gained Codex Remote for steering a desktop session from your phone, the GPT-6 models (Astra in early September, then GPT-6.1 Sol from 29 September, which OpenAI says matches Astra on its DeepSWE test at about a fifth of the cost), a Code Review plugin, and a $500-a-month Pro 500 plan with a faster Astra tier. On 10 September OpenAI opened the Agents API in public beta, which runs the open-source Codex harness as a managed cloud service billed only for tokens and tools. Codex is included, with limits, on every ChatGPT plan from Free upward.
