Copilot Cowork runs complex, long-running tasks across several tools and returns finished work. It needs a Microsoft 365 Copilot user licence. Cowork use is then billed in Copilot Credits, from $0.01 each on pay-as-you-go, or through a prepaid option. Existing Microsoft 365 controls, such as sensitivity labels and audit logs, apply to its output. Microsoft says its own tests found Cowork 30-40% cheaper than Claude Cowork; that is the maker's claim. The earlier "$15/user/mo" figure and the Excel and Agent 365 wording could not be confirmed and were removed.
