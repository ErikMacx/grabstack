Grok Build launched in May 2026 as a terminal coding agent in early beta for SuperGrok and X Premium+ subscribers, with plan review before edits, parallel sub-agents, a headless mode and Agent Client Protocol support. xAI, which joined SpaceX in February 2026 and now calls itself SpaceXAI, has since made the CLI free to try, added memory in September and, on 19 August, brought Grok Build to the web and mobile apps on every plan as an app builder that publishes to grok.me links. It now runs on Grok 4.7 (released 21 September), and a faster Grok 4.7 Fast variant is offered only in Grok Build and Cursor. The $300-a-month price listed here in June no longer applies to trying it.
