NotebookLM answers questions from the sources you give it, with citations back to them. Google's 8 June upgrade moved it onto Gemini 3.5 and gave every notebook a secure cloud computer, so it can write and run code with over 100 curated software skills and return PDFs, Excel sheets, PowerPoint decks, Markdown, CSV, JSON or images that you can then edit. It can also search the web with Google Search and add good sources to the notebook for you. The upgrade went first to Google AI Ultra and Workspace business customers with AI Expanded Access, with wider rollout promised. It makes NotebookLM a grounded research agent that produces finished work, not only a reading aid.
