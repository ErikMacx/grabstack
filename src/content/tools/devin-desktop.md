Devin Desktop is the editor Cognition renamed from Windsurf on 2 June 2026, with plans, settings and extensions carried over. It manages local and cloud agents from one Agent Command Center, shares context between agents through Spaces, runs a local agent called Devin Local, and supports other agents through the Agent Client Protocol. On 10 September Cognition released SWE-2, its own coding model post-trained from Moonshot's Kimi K3, which it says scores 50.0% on FrontierCode 1.1 against Claude Fable 5.1's 50.9% at 64% lower cost; on 11 September it added Fusion, where a frontier model plans and a cheaper model does the work. It is included in the same Devin plans as Devin Cloud, from a free tier to $200 a month.
